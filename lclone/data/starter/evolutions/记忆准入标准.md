# 记忆准入标准（脚本优先，LLM 兜底）

自动捕获先过**确定性闸门**（`lclone/gate.py`，纯脚本、不调 LLM），只有判不准才问 LLM。
**判定标准只写在 `gate.py` 的常量块里（唯一来源）**——本文只讲判定逻辑怎么用，不复述词表，
避免两处漂移。

## 三类判定

- **`skip`** — 明确不值得记，**0 次 LLM 调用**。命中的情形：有效文本太短；剥掉代码块/堆栈后
  没有自然语言；描述「做了什么」（代码改动/修复/重构/新增/迁移这类工作日志）；疑问句；短句寒暄。
- **`candidate`** — 命中**决定性**的「决策/约定/规则」或「教训/经验」说法，直接交 LLM 成卡。
  保守档只收决定性说法；高频泛词（类似「下次」「原来」这种聊天常用词）刻意不收。
- **`uncertain`** — 既没命中强信号，也不构成噪声。先做一次极便宜的 1/0 判定，判「是」才成卡。

## 三条硬规则

- **只看用户轮**：按 `用户：` / `助手：` 切分。助手输出多为「做了什么」，是最大的噪声源。
  宿主**注入块**（插件塞进会话的 skill 全文 / bootstrap 记忆区）先剥掉——它们不是用户说的话，
  否则会用自己的触发词（skill 描述里的「记住」「记一下」、工具表里的 `remember`）命中下面的显式旁路。
- **疑问句优先**：以 `？`/`?` 结尾的句子按提问处理，即使句子里含强信号词也不会判成候选。
- **否定作用域**：信号词前 3 字内出现否定词时该命中不计（「这个不用统一」不算决策）；
  但「不错/不但/不仅/不如/不少」里的「不」不算否定。
- **确定性护栏**：单轮最多成卡 **1 条**（默认一条都不产出，上限不是配额）；
  向量去重 + 归一化文本去重（去空白标点后前 80 字相同视为重复）。

## auto 卡还要过「用户轮证据」

卡片是「用户提出 + 助手确认」的产物，所以它的主张理应在用户轮里有出处（至少命中一个特征片段，
阈值见 `gate.EVIDENCE_RATIO`）。这条拦的是**助手单方面查出来的东西**：工具/skill 装在哪、
目录有没有 .git、容器里跑的是代码还是卷、某开关的当前值（一次 `ls`/`git status`/`docker inspect`
就能重新得到），以及跟本项目决策无关的通用设计常识。它们跟用户轮只是同主题，却没有一句是用户说的。
用户显式说「记一下」的轮次豁免这条——人已经背书了。

## 提炼器自报「空」时不成卡

没有可提炼的内容是**正常结果**（提示词让模型「没有就输出空」）。空哨兵（`空`/`无`/`none`…）、
「未提炼任何卡片」这类元报告回声、以及缺少四段卡标题的回声，一律不落库、不进待确认。

## 用户显式要求

说「记住 / 记一下 / 记下来 / remember」→ **旁路闸门**，长度与噪声都不拦。

## 怎么自测与调参

```bash
lclone gate "决定记忆统一用 SQLite 存"   # 打印判定 / 命中词 / 理由
```

想放宽或收紧，就改 `lclone/gate.py` 顶部的常量块（信号词表、长度下限、单轮上限）；
改完用上面的命令抽查几条真实会话片段即可。

## 不归这里的东西

- 代码改动 / 接口变化 / 修 bug / 重构 → git
- 能改写成 WHEN…THEN… 的契约 → spec（openspec）
