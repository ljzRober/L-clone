# Web 面板

## MODIFIED Requirements

### Requirement: 记忆工作台

Web 面板主页面 SHALL 是记忆工作台：左侧树状层级导航 + 右侧架构图（全局层/项目/模块 三层，每层三个横向划分恒显示），用户通过点击查看、编辑、迁移、添加记忆/项目/模块。

#### Scenario: 默认展示全局层卡片

WHEN 打开主页
THEN 右侧显示全局层大框：三个横向划分（决策/重要修改点/记录，空列显示"无记忆"）+ 嵌套项目框（项目为容器卡，带 charter 整体描述）；左侧为树状导航（全局层 ∞、各项目、展开项目的模块子节点）

#### Scenario: 点击层级筛选

WHEN 点击左侧树状导航的全局层/项目/模块
THEN 图形切换到对应层级视图：全局层（三列+项目框）、项目（三列+嵌套模块框）、模块（三列，叶子层），当前节点高亮

#### Scenario: 拖拽卡片移动记忆

WHEN 点击记忆方块弹出大弹窗，选择归属（全局层/项目）并点击「移动到所选」
THEN 记忆移动到目标层级（全局层 = 上升，项目 = 下降）并刷新图形与计数

#### Scenario: 卡片上升按钮

WHEN 在弹窗中把归属选为「全局层」并点击「移动到所选」
THEN 记忆上升为全局层并刷新

#### Scenario: 添加记忆

WHEN 在某横向划分列头部点「＋」，弹窗填写内容、等级、归属（全局层/项目/模块 三层选择）后确认
THEN 记忆写入该横向划分列并刷新图形与计数

#### Scenario: 添加项目

WHEN 在左侧导航点「＋ 添加项目」并填写项目名/路径/charter 后确认
THEN 项目注册（含 spec 索引同步）并出现在导航与架构图项目区

#### Scenario: 添加模块

WHEN 在项目视图模块大框头部点「＋ 模块」或侧边栏项目下的「＋ 添加模块」并输入模块名
THEN 模块声明创建（允许空模块），出现在项目模块层与树状导航

#### Scenario: 无 spec 区分

WHEN 浏览任意页面
THEN 界面不出现「记忆/spec」区分或 spec 计数；所有记忆即 spec
