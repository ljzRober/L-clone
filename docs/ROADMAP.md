# 路线图

> 回到 [README](../README.md)

## v0(已完成)

- 分层记忆(L0 流水 / L1 决策 / L2 spec 索引)
- 回顾环(带记忆问答)与规范环(边界监督)
- B 确认制 + C 主动触发 记忆写入
- CLI + Web 面板 + REST API
- 竖向分层: 项目命名空间 + 格式无关 spec 索引

## v1(规划中)

- [ ] **MCP server**: 让 Claude Code 等任意 AI 工具直接读写大脑, 对话自动沉淀记忆, 无需复制粘贴
- [ ] **会话自动抽取**: claude-mem 式, 从对话流自动提炼, 走 B 确认制
- [ ] **PostgreSQL + pgvector**: 多设备并发时替换 SQLite
- [ ] **定时学习任务**: 每日自动汇总项目状态, 主动提醒
- [ ] **记忆冲突检测与档案刷新**: 发现新旧记忆矛盾时提示确认

## 设计取舍记录

| 决策 | 理由 |
|---|---|
| 记忆在服务器, 模型走 API | 数据可控 + 免 GPU 运维 + 永远用最新模型 |
| spec 权威留在项目仓库 | spec 是项目产物, 应随 git 版本化、可评审; 大脑只建索引 |
| B 确认制 | AI 自动总结不可全信, 你盖章后才生效 |
| 格式无关 spec 索引 | 不绑定 OpenSpec/ADR 等任何工具, 按路径模式启发式识别 |
